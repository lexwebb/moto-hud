# Spleen (bitmap)

Monospaced pixel fonts by Frederic Cambus — https://github.com/fcambus/spleen  
License: BSD-2-Clause (see LICENSE).

Pregenerated sizes used by Moto HUD (exact BDF pixels, never scaled):

- `spleen-6x12.bdf` — meta / footers
- `spleen-8x16.bdf` — ETA / body
- `spleen-12x24.bdf` — road / titles
- `spleen-16x32.bdf` — distance

Do not generate intermediate sizes. If design needs another size, add another official Spleen BDF.
